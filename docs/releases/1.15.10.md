# Metol 1.15.10

> 2026-11-27 · 英文包修好：不再「装了但双击 EV 没反应」

## 谁需要升

**装英文包（EN）的用户必须升。** 1.15.8 和 1.15.9 的英文包里，双击 EV 打不开面板，
菜单进不去，也就没有卸载入口 —— 人被锁在外面。中文包不受影响，但这一版两边都加了兜底。

## 病根

英文面板 `nxui_en.arm` 停在 11-14 那次编译，之后再没重编过。

- 11-20 起启动器 `nxui.sh` 改成一次装两层（LUT + FilmLab），多传三个参数
  `--lut-recipes` / `--lut-engine` / `--lut-recipes-vlog`。
- 老英文面板的参数表里没有这三项，落到 `else` 分支打一行 `Usage:` 就 `return 2`。
- `nxui.sh` 是后台起进程、成败都 `exit 0`，外层看起来「成功」，实际一个窗口都没建出来。

结果：双击 EV 没反应、EV+WiFi 没反应、菜单和卸载入口全部摸不到。
中文包装的是当前二进制，认得这些参数，所以只有英文包中招。

## 修了什么

1. **重编英文面板**：从当前 `nxui.c` 生成，与中文面板同代。顺带补上 11 条
   11-20 之后新增的英文文案；EN 也因此补上了新版 292 px 菜单、面板内横幅、
   多行对话框、LUT / FilmLab 双页签。
2. **打包加门**：`pack_release.py` 打英文包之前，会检查面板二进制是否认得
   启动器传的每一个开关、是否比源码新。不认就中止打包，不再「文件在就发」。
3. **双击 EV 有兜底**：面板 1 秒内没露头，自动退回经典 popup（`mod_gui`）。
   以后面板再出问题，至少菜单和卸载入口还在，不会把人锁在外面。

### 11-28 真机复验：兜底原先还差一层（已补）

在机上把 `nxui.arm` 换成「exec 成功、250 ms 后 `exit 2`」的假面板：`EV_EV.sh`
的 400 ms 存活窗口正确判定失败（`pid 1446 → none`）并调 `classic`，**但
`mod_gui` 始终没起来**。

原因：`loadgui.sh` 自己也优先走 nxui——

```bash
if [ -x /opt/usr/nx-ks/nxui.sh ] && /opt/usr/nx-ks/nxui.sh available; then
    /opt/usr/nx-ks/nxui.sh menu
    exit $?
fi
```

而 `nxui.sh available` 只查「二进制存在 + 可执行 + 机型 + 无 disabled」，
坏二进制照样通过。⇒ `classic` 起的 `loadgui` 又拉起同一个坏面板，`mod_gui`
永远轮不到，人还是被锁死。判定对了、退路没通。

修：`loadgui.sh` 加 `NXUI_FALLBACK=1` 开关——置 1 时跳过 nxui 分支，保留后面
prefman / DIALMODE / gen_menu 的准备逻辑，直接落到 `mod_gui`；`EV_EV.sh` 的
`classic()` 带上它。复验：判定 `pid 1446 → none`，`mod_gui_after=running`，
`nxui.arm` 恢复 md5 `efbe7a86`。

## 已经被锁住的怎么退

不需要 SSH，也不需要菜单：把包里 `uninstall_pkg/` 的三个文件
（`info.tg`、`nx_cs.adj`、`uninstall_direct.sh`）拷到 SD 卡根目录，插卡即卸载并自动重启。

卸载完再重新装 1.15.10 的英文包。

## 装法

和其他版本一样：`Metol-1.15.10.zip`（或 `-EN`）解压到 SD 卡根目录 → 插卡 →
屏上「同步完成」→ 自动重启。

**注意**：`cp -ar` 只覆盖不删除，SD 卡上的 `scripts/` 是母本。手动更新时要把新文件
拷进 SD 卡的 `scripts/`，否则下次装机还是旧版。

## 随包携带 Log117 gamma 引擎（V-Log 开箱可用）

1.15.10 之前 V-Log 曲线要另装引擎，没装时菜单项只报「缺失」。现在闭包直接进包：

| 项 | 值 |
|---|---|
| 位置 | 包内 `metol-extensions/log117/`（解压后在 SD 卡根） |
| 内容 | 32 文件 1.3 MB：`gamma-reload.sh`、15 个 `nxl-*.arm`、`data/clean-log/`、`payload.sha256` |
| 身份 | Unified R1 `eafc274`，`payload.sha256` pin `a30ad550a68653d475aee8201e20dfbd16fd91802f2f5a41ea2e49c60fdcbf6f` |
| 装机行为 | `install.sh` 同步完 `scripts/` 后调 `gamma-log117-install.sh install`：**只装不激活**，旧 gamma 树整体备份为 `gamma-before-log117-<时间戳>-<pid>`，运行时 `state/` 保留，幂等 |
| 手动 | `sh /opt/usr/nx-ks/gamma-log117-install.sh check` / `install`，日志 `/tmp/nx-ks-gamma.log` |
| 体积 | 中英文包各增加约 0.8 MB |

> 引擎装好 ≠ V-Log 已开。开关仍走 **EV + AEL** 或菜单，且要求 A18 回原厂（`lut.sh off`）、
> PW 中性、未插 USB —— 三条不满足直接拒绝，明细在 `/tmp/nx-p0/vlog-gate.log`。
> 反过来说：装了引擎也不会替你改运行态，`vlog.sh off` 或重启即回原厂 gamma。

## 救砖：免拆机固件恢复（本次随包补文档）

相机被搞到开不了机（`nx-on-wake` 装崩、`systemctl rescue`、系统或休眠损坏）时，
不需要拆机、不需要短接主板、不需要串口、也不需要 `downloader.bin`：

1. 官方**未修改**的 `nx500.bin`（如 v1.12）解压到干净的 **FAT32** SD 卡根目录
2. 拔电池 → 插卡 → 后屏**完全翻到自拍位** → 装回电池（保持关机）
3. 同时按住 **MOBILE(Wi-Fi) + AEL + 全按快门**，再拨电源开机
4. 出现蓝底 `Recovery Mode`（`F/W Check` / `Update` / `Update Finish`）后松手，按提示**长按快门**刷入

刷写期间严禁断电、拔电池，直到 `Update Finish`；只认官方固件。这条路径已在软砖 NX500 上
完整验证恢复正常开机，**NX1 未验证**（GPIO 不同且无翻转屏）。原理见
[`BOOT0_ANATOMY.md`](https://github.com/WApaperplane/nx500-dnloader/blob/main/docs/BOOT0_ANATOMY.md)
（`GPIO_WIFI_KEY` 19 / `GPIO_SHUTTER_KEY2` 27 / `GPIO_FLIPUP_INT` 30 / `GPIO_AEL_KEY` 31）。

> 刷机只重写系统分区，`/opt/usr/nx-ks` 所在的 **p14 不受影响** —— 固件刷完插回 SD 卡做一次
> 增量同步，mod 就回来了。但 p9 休眠快照在刷机后是否保留**没有核实过**，重装 mod 之前先跑
> 一遍只读探针比凭猜稳。
