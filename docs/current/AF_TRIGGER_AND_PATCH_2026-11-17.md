## 0. 结论

| # | 结论 | 置信度 |
|---|---|---|
| 1 | **SLOW-AF 不是独立的低照度功能**，而是 CAF（连续 AF）模块内部的一个"慢速扫描"子模式（`CAF::SlowAFStart` / `onStartSlowAF`） | 高 |
| 2 | 它的整条链**不读任何照度量**（ISO / BV / LV / Tv / 主脸 Y 都没有），判据只有 AF 内部状态位 + CAF 状态 + 镜头通信结果 | 高 |
| 3 | **v1.12 里这条路径实际上断了**：唯一业务入口 `CIQIfAf::Start(2)` 的调用者 `0x800ABC8C` 全镜像零引用；另一入口 `slafsta` 的宿主 `0x802FB474` 也无静态引用（三层扫描均 0 命中） | 高（负证据） |
| 4 | 同族的 **S0-AF 才是活的**：入口 `0x800ABC1C` 挂在 `C3AStateLockCAF` 虚表槽（`0x80577064+0x2C`），由连续 AF 状态机驱动 | 中高 |
| 5 | `Average Y Data of Main Face` **只被一个调试打印函数消费**，没有进入 AF/AE 决策 | 高 |
| 6 | `PafAdjust.csv` **不是运行时加载的参数文件**，是 PAF 工厂调整工序写出的 CSV 日志名；参数实体在 RAM（`0x815555B8` / `0x81555B08`），**可运行时改写** | 高 |

> 一句话：**SLOW-AF 由 AF 状态机/命令触发，不由暗光触发；而且 v1.12 里这条路是死的。**
> 想从"低照度"切入改善 AF，这条不是入口。

## 1. 三个可改参数的初值（最小补丁落点）

`ng` / `ok` / `small` **不是散落在算法里的立即数**，而是 AF 管理器构造函数一次性写入
全局 AF 上下文的**三个相邻 int 字段**。

| 参数 | 默认 | 绝对地址 | 相对 GAF | 写入指令 | 文件偏移 |
|---|---|---|---|---|---|
| `ng`（连续 NG 几次停止跟踪） | **8** | `0x8155044C` | `GAF+0x44` | `0x8029B558` `mov r2,#8` → `0x8029B56C` `str r2,[r5,#0x22c]` | `0x29C558` / `0x29C56C` |
| `small`（小目标抖动次数） | **4** | `0x81550450` | `GAF+0x48` | `0x8029B4F8` `mov r3,#4` → `0x8029B500` `str r3,[r5,#0x230]` | `0x29C4F8` / `0x29C500` |
| `ok`（连续 OK 几次开始跟踪） | **4** | `0x81550454` | `GAF+0x4C` | 同上 `r3=4` → `0x8029B504` `str r3,[r5,#0x234]` | `0x29C504` |

链路自证：函数入口 `0x8029B4E4`（`push {r3,r4,r5,r6,r7,r8,sl,lr}`），`0x8029B4E8`
装 `r5`（`ldr r5,[pc,#0x3b0]`，字面池 `0x8029B8A0 = 0x81550220`）；
`0x81550220 + 0x22C = 0x8155044C = GAF+0x44` —— 基址与偏移三条指令互相印证，无歧义。

唯一调用者 `0x802AEC80`（`bl 0x8029B4E4`）是 AF 管理器的一次性构造入口
（同函数内还调 `0x802c01bc`（AF 算法单例 getter）、`0x802b7954`、`0x802b9b3c` 等 20 余个子系统构造器）。

> 补丁含义：改这三个数不需要动算法，但要放对**构造期**的写入点，否则会被后续初始化覆盖。

## 2. 两个"看起来像、其实不是"的东西

| 误认 | 真相 | 判据 |
|---|---|---|
| `PafAdjust.csv` 是运行时参数文件 | PAF **工厂调整工序**写出的 CSV 日志名；参数实体在 RAM `0x815555B8` / `0x81555B08` | 全镜像无读取该 CSV 的代码路径 |
| `Average Y Data of Main Face` 参与 AF 决策 | 只被一个调试打印函数消费 | 引用点唯一且落在打印函数内 |

## 3. 边界

1. 结论 3 是**负证据**（三层扫描零命中），不等于运行时绝对不可能被触发；但静态层面没有可达路径。
2. 三个初值的地址是 `GAF+0x44/0x48/0x4C`，依赖 **GAF = `0x81550408`** 这个前提
   （见 `AF_MOTION_AND_LOWLIGHT` §5 的修正）。
3. 没有任何补丁被编写、编译或上机。
